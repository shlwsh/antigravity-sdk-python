# 10 示例手册（examples/）

本章对仓库 [`examples/`](../../examples/) 目录下的**全部可运行示例**做统一说明：每个用例的**构成、作用、运行方法与验收要点**。运行前请先完成 [09_项目运行与功能全景](./09_项目运行与功能全景.md) 中的 venv、`.env` 与 `hello_world` 验证。

---

## 目录结构

```
examples/
├── getting_started/     # 入门：单文件、单特性（18 个 .py）
├── deep_dives/          # 进阶：多特性组合的小型应用（8 个 .py）
└── resources/           # 共享资源（MCP 服务、样例文本等）
```

| 子目录 | 定位 | 建议顺序 |
| :--- | :--- | :--- |
| `getting_started/` | 每文件演示 **一个** SDK 概念 | 按本章表格「推荐学习顺序」 |
| `deep_dives/` | 组合 Agent、Hook、MCP、多 Agent 等 | 入门示例跑通后再试 |
| `resources/` | 被其它示例 **引用**，通常不单独当「Agent 示例」运行 | 配合 `mcp_tools` / `interactive_cli` |

---

## 通用运行方式

```bash
cd /path/to/antigravity-sdk-python
source .venv/bin/activate
set -a && source .env && set +a

# 方式 1：从仓库根目录（推荐，路径最不易错）
python examples/getting_started/hello_world.py

# 方式 2：进入子目录
cd examples/getting_started
python hello_world.py
```

**共同依赖：** `pip install google-antigravity`（含 `localharness` 二进制）、`GEMINI_API_KEY`（`.env` 或环境变量）。

**共同模式：**

```text
LocalAgentConfig(...)  →  async with Agent(config)  →  await agent.chat(...)
                      →  await response.text() / 流式迭代 response
```

## 推荐学习顺序（入门）

```mermaid
flowchart LR
  A[hello_world] --> B[streaming]
  B --> C[custom_tools]
  C --> D[policies]
  D --> E[hooks]
  E --> F[mcp_tools]
  F --> G[persistence]
  G --> H[deep_dives 任选]
```

| 顺序 | 文件 | 理由 |
| :---: | :--- | :--- |
| 1 | `hello_world.py` | 最小闭环 |
| 2 | `streaming.py` | 流式与 thoughts |
| 3 | `custom_tools.py` | 扩展能力 |
| 4 | `policies.py` | 安全基线 |
| 5 | `hooks.py` | 可观测与拦截 |
| 6 | `mcp_tools.py` | 外部工具生态 |
| 7 | 其余 getting_started | 按兴趣选读 |
| 8 | `deep_dives/` | 综合场景 |

| 项 | 说明 |
| :--- | :--- |
| **作用** | **异步对等**群聊：无固定轮次，各 Agent 独立 loop，`asyncio.Condition` 在新消息时唤醒。 |
| **核心 API** | `AsyncChatRoom`、`pass_turn`、多 Agent 并行 `async with`、120s 超时 |
| **构成** | 三 Agent 各跑 `_agent_loop` → 连续 pass 或超时结束 → 打印 transcript。 |
| **运行** | `python examples/deep_dives/async_chat.py` |
| **前置** | 最长约 **120s** |
| **验收** | 至少 2 个 Agent 有实质回复；正常结束或超时。 |
| **关联章节** | [07](./07_高级特性.md) |

**与 `round_based_chat` 对比：**

| 维度 | round_based_chat | async_chat |
| :--- | :--- | :--- |
| 同步方式 | 每轮 gather，全员同时收到本轮上下文 | 谁先 chat 完成谁可能接着说 |
| 触发器 | 有 moderator `every(60)` | 无 |
| 结束条件 | 全员 pass 或达最大轮数 | pass 计数或 120s 超时 |

## 六、排错提示

| 现象 | 可能原因 |
| :--- | :--- |
| `ModuleNotFoundError: google.antigravity` | 未激活 venv 或未 `pip install google-antigravity` |
| `A Gemini API key is required` | 未 `source .env` |
| `mcp_tools` / `interactive_cli` 失败 | `python3` 路径、`resources/mcp_server.py` 不存在或端口占用 |
| `multimodal.py` 读图失败 | 缺少 `resources/example_image.png` |
| `policies` / 文件工具越权 | `workspaces` 默认限制 cwd，路径需在允许目录内 |
| MCP stdio 无输出 | 检查子进程 `mcp_server.py --transport=stdio` 是否被正确拉起 |

更多环境说明见 [09_项目运行与功能全景](./09_项目运行与功能全景.md)；Harness 原理见 [02 § Local Harness](./02_核心架构.md#️-local-harness-二进制是什么)。
