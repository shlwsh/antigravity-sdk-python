# 01 快速开始

本章将引导你从零开始安装 Google Antigravity SDK，并运行最基础的 Agent 示例。

---

## 🛠️ 安装

```bash
pip install google-antigravity
```

> [!IMPORTANT]
> **关键运行依赖**：
> Google Antigravity SDK 依赖于一个预编译的 Go 语言运行时二进制文件（运行在 Local Harness 层）。该二进制文件已经打包内置在发布到 PyPI 的平台特定的 Wheel 轮子中。
> 
> **仅克隆此 Git 仓库是不足以直接运行 SDK 的**。你必须始终通过 `pip install google-antigravity` 从 PyPI 安装以获取完整的运行时环境。

---

## 🔑 环境配置

在运行代码之前，你需要提供 Gemini API Key。SDK 会在运行时自动检索环境变量 `GEMINI_API_KEY`：

```bash
export GEMINI_API_KEY="your_api_key_here"
```

如果你希望通过 Vertex AI 运行，也可以使用 GCP 的认证信息。

## 🚀 Hello World 示例

我们来编写第一个简单的 Agent。这个 Agent 会向 Gemini 模型发送一条简单的消息并打印回复。

### 代码实现

新建文件 `hello_world.py`：

```python
import asyncio
from google.antigravity import Agent, LocalAgentConfig

async def main() -> None:
    # 1. 创建默认的本地 Agent 配置
    # 默认模型为 "gemini-3.5-flash"
    config = LocalAgentConfig()

    # 2. 使用异步上下文管理器 `async with` 启动 Agent 会话。
    # 这一步会在后台拉起 Local Harness 运行时二进制，并建立 WebSocket 连接。
    async with Agent(config) as my_agent:
        prompt = "请对我说 'Hello World!'"
        print(f"User: {prompt}")

        # 3. 发送聊天信息并获取响应对象
        response = await my_agent.chat(prompt)

        # 4. 等待并聚合完整的文本响应
        response_text = await response.text()
        print(f"Agent: {response_text}")

if __name__ == "__main__":
    asyncio.run(main())
```

## 🌊 流式响应 (Streaming) 示例

当执行复杂推理（如 riddle 解密）或需要即时呈现打字机效果时，流式输出必不可少。SDK 支持**思维链 (Thoughts) 流**和**最终答案 (Text) 流**的并行或顺序提取。

### 代码实现

新建文件 `streaming_demo.py`：

```python
import asyncio
import sys
from google.antigravity import Agent, LocalAgentConfig

async def main() -> None:
    config = LocalAgentConfig()

    async with Agent(config) as my_agent:
        prompt = (
            "请解答这个谜题：我没有嘴巴却能说话，没有耳朵却能听到。我没有身体，"
            "但风一吹我就活了。我是什么？并请详细分析你的思考过程。"
        )
        print(f"User: {prompt}\n")

        # chat() 方法本身会立刻返回一个 response 响应流对象，不阻塞网络
        response = await my_agent.chat(prompt)

        # 1. 流式读取模型的推理思维链 (thoughts)
        # 这对于支持推理能力的模型（如 Gemini 2.0 Thinking/Gemini 3.5）非常有用
        print("Agent 正在思考 (流式思考中)...")
        print("-------------------------------------------------------")
        async for thought in response.thoughts:
            print(thought, end="", flush=True)
        print("\n-------------------------------------------------------\n")

        # 2. 流式输出最终对话答案
        # 通过直接迭代 response 对象 (async for token in response) 即可获取答案文本
        print("Agent 最终回答:")
        print("-------------------------------------------------------")
        async for token in response:
            sys.stdout.write(token)
            sys.stdout.flush()
        print("\n-------------------------------------------------------\n")

if __name__ == "__main__":
    asyncio.run(main())
```

## 🛡️ 安全模式：只读与写权限控制

出于安全考虑，SDK 默认以**只读模式**（Read-only Mode）启动。

在只读模式下，Agent 无法使用可能改变系统状态或执行系统修改的内置工具（如 `run_command`、`edit_file`、`create_file` 等），只会暴露只读内置工具（如 `list_directory`、`view_file` 等）。

### 开启写权限/全工具能力

要想让 Agent 拥有文件修改、命令行执行等完整能力，需要在配置中显式传递 `CapabilitiesConfig`：

```python
from google.antigravity import Agent, LocalAgentConfig
from google.antigravity.types import CapabilitiesConfig

config = LocalAgentConfig(
    # 传入 CapabilitiesConfig 实例会默认开启所有内置工具（包括写和命令执行）
    capabilities=CapabilitiesConfig(),
)
```

> [!WARNING]
> **安全警告**：
> 开启写权限或连接外部 MCP 服务器时，如果没有任何安全拦截策略，SDK 会在启动时抛出 `ValueError`。你必须同时为其提供安全决策策略（Policies）或拦截 Hook。详情参见 [05_生命周期拦截与安全策略.md](./05_生命周期拦截与安全策略.md)。
